# Квартира в кубах

Интерактивная 3D-сцена квартиры: планировка, размеры (сетка 1×1 м), режим прогулки
от третьего лица, слой отделки, виды из окон.

Один самодостаточный файл — `index.html` (three.js и текстуры встроены,
внешних зависимостей и сети не требуется).

## Запуск локально

Просто открыть `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Деплой

Конфигурация веб-сервера для деплоя — в `deploy/angie.conf`.

## Управление

- ЛКМ — вращать, колесо — зум, ПКМ или пробел — сдвиг
- «От первого лица»: стрелки ↑↓ — идти, ←→ — повернуться (WASD тоже работает),
  мышь — оглядеться, колесо — идти, ПКМ — шаг в сторону
