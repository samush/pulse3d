# Квартира в кубах

Интерактивная 3D-сцена квартиры: планировка, размеры (сетка 1×1 м), режим прогулки
от третьего лица, слой отделки, виды из окон.

Статика без сборки и внешних зависимостей: `index.html` + `plan.js`
(геометрия квартиры) + `app.js` (код сцены) + `three.min.js` (впендоренный
three.js, текстуры встроены). Живая страница: https://samush.github.io/pulse3d/
(GitHub Pages, деплой с `main`).

Для разработки: структура данных — `docs/GEOMETRY.md`, инструменты —
`tools/` (правка геометрии и smoke-тест), спецификация помещений —
`APARTMENT.md`.

## Запуск локально

Просто открыть `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Спецификация помещений

Номера комнат и их размеры — в [APARTMENT.md](APARTMENT.md)
(нумерация по плану БТИ, совпадает с `rooms[].id` в сцене).

## Деплой

Конфигурация веб-сервера для деплоя — в `deploy/angie.conf`.

## Управление

- ЛКМ — вращать, колесо — зум, ПКМ или пробел — сдвиг
- «От первого лица»: стрелки ↑↓ — идти, ←→ — повернуться (WASD тоже работает),
  мышь — оглядеться, колесо — идти, ПКМ — шаг в сторону

- «Разметка» (в виде сверху): точка / отрезок / прямоугольник кликами по плану, карточка метки
  с координатами и кнопка «Скопировать для агента». Клавиши: 1/2/3 — инструмент, Esc — отмена,
  Delete — удалить, Ctrl+Z — отменить.

- «Расстановка» (в виде сверху): клик по предмету, перенос и поворот, варианты расстановки
  с сохранением в браузере, текст и файл для агента.

## Проверка

```bash
npm i --no-save playwright && npx playwright install chromium   # один раз на окружение
node tools/check.js                                              # локальная копия
node tools/check.js https://samush.github.io/pulse3d/            # живая страница
```

Тест проверяет загрузку без ошибок, 10 помещений и площади, вид «Сверху» и шаг в прогулке;
скриншоты кладёт в `tools/out/`. Если Chromium не запускается, он выходит с кодом 2 и
подсказкой по установке (системные библиотеки: `npx playwright install-deps chromium`, нужен root).
Базовые скриншоты и сверка площадей на момент начала работ по плану: `tasks/baseline/`.
