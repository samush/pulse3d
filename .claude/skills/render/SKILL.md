# Визуализация ракурса

Конвейер: чистый кадр сцены с закреплённой камеры → Gemini → картинка в `renders/<ракурс>/`.

## Как запустить

```bash
node tools/render.js --list                  # список ракурсов (CAMS в app.js)
node tools/render.js r4-door                 # кадр + генерация
node tools/render.js r4-door --frame-only    # только чистый кадр, без API и без денег
node tools/render.js r4-door --note "вечер, шторы задёрнуты"
node tools/render.js r4-door --reuse-frame    # взять снятый кадр, не открывать браузер
```

Ключ `GEMINI_API_KEY` приходит из окружения (`hub run claude`). Нет ключа — скрипт скажет об этом и не потратит ничего. Ответ 429 значит, что в проекте ключа не включён биллинг: у image-моделей нет бесплатного тарифа.

Результат: `renders/<ракурс>/<дата-время>.jpg` и рядом `.json` с промптом и параметрами. Чистый кадр — `renders/frames/<ракурс>.png` (в git не идёт, перезаписывается).

## Промпт

Весь текст — `renders/STYLE.md`: общая часть плюс раздел `## <ракурс>`, если он есть. Инструкции не дублировать в чате и не хардкодить в скрипте — правится только этот файл.

## Разбор результата

После генерации прочитать оба изображения (`Read`) — чистый кадр и результат — и сверить по списку:

1. Состав: не появилось лишних предметов, ничего не пропало.
2. Расстановка: каждый предмет там же, где на кадре; повороты и пропорции те же.
3. Геометрия: стены, окна, двери, проёмы не сдвинулись; высота потолка не выросла.
4. Ракурс: та же точка съёмки и тот же угол.
5. Материалы: соответствуют `renders/STYLE.md` и назначенным покрытиям (`ITEMS.coat`, `materials.js`).

Что не сошлось — коротким списком в ответ пользователю, с предложением: поправить раздел ракурса в `STYLE.md` или перегенерировать с `--note`.

## Цена

`gemini-3.1-flash-image` (по умолчанию) — $0.067 за картинку 1K/2K, `--model gemini-3.1-flash-lite-image` — $0.034 (только `--size 1K`), `--model gemini-3-pro-image` — $0.134. Бесплатного тарифа у этих моделей нет.
