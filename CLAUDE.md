# pulse3d — 3D-сцена квартиры для планирования ремонта

Статическая страничка: three.js-сцена квартиры (10 помещений по плану БТИ).
Хостится на GitHub Pages: https://samush.github.io/pulse3d/ — деплой
автоматический с ветки `main`, поэтому ничего публиковать отдельно не нужно,
но в `main` должно попадать только проверенное.

## Рабочий процесс

- Коммитить и пушить сразу в `main`, без PR (репозиторием пользуется один человек).
- Задачи в чате ставятся по номерам помещений («в комнате 3…») — эталон
  номеров, площадей и размеров: `APARTMENT.md`.
- Перед пушем прогнать smoke-тест: `node tools/check.js`
  (один раз на окружение: `npm i --no-save playwright && npx playwright install chromium`;
  системные библиотеки Chromium ставятся от root: `npx playwright install-deps chromium`).
  Без браузера тест завершается кодом 2 с текстом обеих ошибок запуска — это не «прошёл».
  После деплоя можно проверить и живую страницу:
  `node tools/check.js https://samush.github.io/pulse3d/`.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | разметка, стили, панель UI; подключает три скрипта ниже |
| `plan.js` | `const PLAN` — вся геометрия квартиры (см. `docs/GEOMETRY.md`) |
| `app.js` | код сцены: рендер, режимы, прогулка, отделка, двери `DOORS`, панорамы `VIEWS` |
| `three.min.js` | впендоренный three.js — не редактировать |
| `APARTMENT.md` | спецификация помещений по БТИ — эталон номеров/площадей |
| `tools/plan.py` | работа с геометрией: `areas`, `check`, `remap` (сдвиг граней стен вместе с окнами/дверями/проёмами), `selftest` |
| `tools/check.js` | smoke-тест на Playwright + скриншоты в `tools/out/` |
| `deploy/angie.conf` | конфиг веб-сервера для альтернативного самостоятельного хостинга |

Внешних зависимостей у страницы нет (кроме необязательного гугл-шрифта) —
работает и с `file://`, и на Pages.

## Сетка-адресация (галочка «Сетка-адресация»)

Пользователь задаёт положение объектов адресами клеток, а не метрами:

- Метровые клетки пола: буквы A,B,C… с запада на восток, цифры 1,2,3… с севера
  на юг, от фиксированного `PLAN.meta.origin` (угол A1; изменение контура адреса не меняет).
  Подпись — в северо-западном углу клетки. Адрес на границе клеток — у клетки восточнее/южнее.
- Точнее — дециметры внутри клетки: `D7+26` = от угла клетки D7 два дм на восток,
  шесть на юг. Пересчёт: x = minX + 3×1 + 0.2; z = minZ + 6×1 + 0.6.
- Высота: H в дециметрах от чистового пола, H0–H27 (потолок 2,7 м). В сцене чистовой пол — `y=0`, см. `docs/GEOMETRY.md` («Высоты»).
- Объект описывается кубом: «от C2+00 до стены на север, глубина 6 дм, H0–H9».

## Правила правок геометрии

1. Геометрию не править руками: грани стен совпадают по координатам в
   `rooms[].poly`, `slabs`, `cells` — двигать только через
   `python3 tools/plan.py remap …` (инвариант описан в `docs/GEOMETRY.md`).
2. `rooms[].area` — площади БТИ, менять только если реально меняется
   планировка; при расхождении полигона и БТИ эталон — БТИ (`APARTMENT.md`).
3. После правок: `python3 tools/plan.py check` (согласованность и площади) и
   `node tools/check.js` (сцена грузится, высоты, скриншоты глазами).
4. Проёмы, окна, двери и контуры санузлов живут в `PLAN` (`doors`, `windows`, `openings`,
   `baths`), не в `app.js` — тогда `remap` двигает их вместе со стеной.
5. `tools/out/` — артефакты проверки, в git не коммитятся.
