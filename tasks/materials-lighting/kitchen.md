## Правила для M4 (по классам предметов)

1. **Корпусная мебель** (шкафы, тумбы, консоли, фасады): `cabinetPaint` на фасады и видимые торцы (`base`, `upper`, `door`, `wdoor`,
   `wpanel` вне кухни); корпус за фасадом не трогать. Цвет один на квартиру, если пользователь не задаст другой.
2. **Столешницы и полки из дерева**: `oakFurniture` без поворота — волокна идут вдоль V, то есть вдоль длины горизонтальной детали
   по z и вдоль высоты вертикальной. Для детали, вытянутой по x, нужен отдельный preset с `rotation:90`, не поворот общей текстуры.
3. **Обивка**: `sofaWeave` на обивку, кант и подушки одного предмета (имена GLB `upholstery`, `piping`, `cushion`). Матрасы (`kmat`),
   подушки кроватей (`pillow`), покрывала (`cover`) — свои presets (`curtainLinen`/будущие), не `sofaWeave`.
4. **Ковры** — `rugPile`, **шторы** — `curtainLinen`, тюль — тот же набор с прозрачностью исходного материала (`tulle`).
5. **Плитка и керамогранит**: `tile6060` для `white`/`grey`/`whiteWall`, `tile60120` для `tile`; всегда с явной `rough`, не из карты.
6. **Пластик** (рамки розеток, корпуса ламп): `plastic`, цвет из концепта; рассеиватели — класс `emitter`, без покрытия.
7. **Сантехника, хром, стекло, экраны**: без покрытия, класс достаточен.
8. Покрытие задаётся в `ITEMS` полем `coat:{…}` по имени материала GLB, ключу `ITEM_MATS` или слоту; для повторяющихся предметов —
   общая константа (как `CHAIR4`). `VIZ.coat` — только для проверки в консоли, не для постоянного назначения.

## Отклонения от референса и почему

- Стулья и стол — дуб, не тёмное дерево референса: §2 задаёт дуб, тёмный тон — отдельное решение пользователя (сделать preset с `tint`).
- Фасады матовые, не глянцевые: §2. Фартук — гранит, референс показывает светлый терраццо; замена набора — вопрос T2.
- Дневные солнечные пятна референса не воспроизводятся: свет — L1.
- Тени от встроенных спотов на стенах (кадр B, над диваном): нейтральное солнце светит сквозь потолок (он не отбрасывает тень, M0),
  а корпуса спотов L0g — отбрасывают. Это свойство нейтральной схемы, не материалов; в схеме ламп L1 источник под потолком.
