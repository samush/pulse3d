# Формат данных сцены (`plan.js`)

Вся геометрия квартиры — объект `const PLAN` в `plan.js`. Координаты в метрах,
в плане: `x` — вправо, `z` — «вниз» по плану БТИ, `y` — высота (потолок `H=2.7`
задан в `app.js`). Все стены осепараллельны.

## Структура PLAN

```
{
  "outer":  [[x,z],...],        // контур квартиры (внешняя граница стен)
  "rooms":  [ { id, poly, label, cells, area }, ... ],   // 10 помещений
  "slabs":  [ { y0, y1, polys:[{s:[[x,z],...], h:[дыры]}] }, ... ],
  "slabsR": [ ... ],            // то же — стены, снесённые в ремонте? (слой)
  "windows":[ { x|z, z0,z1|x0,x1, y0, y1, nx|nz, img }, ... ]
}
```

- **`rooms[].id`** — номера по плану БТИ, эталон номеров и площадей —
  `APARTMENT.md` в корне.
- **`rooms[].poly`** — полигон пола комнаты (внутренние грани стен).
- **`rooms[].area`** — площадь БТИ; показывается в подписи при клике на точку.
  Габариты в подписи вычисляются из bbox полигона.
- **`rooms[].cells`** — ячейки `[x, z, w, h, чётность]` для режимов
  «кубы 1 м³» и клетчатой разметки пола. Сетка привязана к углу комнаты,
  чётность — шахматный порядок.
- **`slabs`/`slabsR`** — стены как полигоны-«ленты» по высотным поясам
  `y0..y1` (0–0.55 подоконный, 0.55–2.1 основной, 2.1–2.3 над дверями,
  2.3–2.7 до потолка). Проёмы — разрывы в полигонах или дыры `h`.
- **`windows`** — окна на наружных стенах, `img` — индекс встроенной
  панорамы из `VIEWS` в `app.js`.

Двери (`DOORS`), проход на балкон и виды из окон заданы в `app.js`.
Логика плинтусов ищет дверь на стене с допуском 0.45 м от грани.

## Главный инвариант

Грань стены имеет ОДНУ и ту же координату во всех структурах: в poly комнаты,
в полигонах slabs, в краях cells. Поэтому стены двигаются только синхронным
ремапом «ось + старое значение + диапазон по перпендикуляру»:

```bash
python3 tools/plan.py remap z 4.848 4.864 0.85 5.50   # юг комнаты 1
python3 tools/plan.py areas                           # сверка с БТИ
```

Диапазон нужен, потому что одно значение координаты может принадлежать разным
стенам (пример: x=8.215 был гранью и кухни 4, и санузла 8).

После любых правок геометрии: `node tools/check.js` — сверит площади
полигонов с записанными и снимет скриншоты в `tools/out/`.
