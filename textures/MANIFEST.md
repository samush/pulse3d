# Текстуры покрытий (этап T, materials-lighting)

Локальные PBR-наборы 1K для покрытий из `tasks/materials-lighting/PLAN.md` §11.T. Ни одна карта не грузится извне:
всё лежит в `textures/<ключ>/`. Код этот каталог пока не читает — подключение делает этап M1a.

Общий контракт файлов (одинаков для всех наборов, кроме `checker`):

| Файл | Что | Цветовое пространство |
|---|---|---|
| `color.jpg` | базовый цвет (albedo), без запечённых теней и бликов | sRGB (`THREE.sRGBEncoding`) |
| `normal.jpg` | нормали в конвенции OpenGL (Y+ вверх), как ожидает three.js | линейные данные |
| `rough.jpg` | абсолютная шероховатость, белый = шероховатый | линейные данные |

Все карты 1024×1024, бесшовные (tileable), `RepeatWrapping`. «Размер» ниже — сторона квадрата в метрах, который покрывает
одна карта; `repeat = 1/размер` при UV в метрах. Пометка **оценка** — ambientCG не публикует физический размер этого набора,
число подобрано по видимому масштабу рисунка и подлежит проверке checker-картой в M1b.

Источники: [ambientCG](https://ambientcg.com) (автор Lennart Demes) и [Poly Haven](https://polyhaven.com). Лицензия у всех —
**CC0 1.0** (public domain, атрибуция не требуется). Дата загрузки: 2026-09-07.

Что изменено: из zip ambientCG (`<Asset>_1K-JPG.zip`) взяты только `_Color`, `_NormalGL`, `_Roughness` и переименованы;
с Poly Haven взяты `_diff_1k.jpg`, `_nor_gl_1k.jpg`, `_rough_1k.jpg` и переименованы. Пиксели, размер и качество JPEG
не менялись. Остальные карты исходников (AO, Displacement, NormalDX, Metalness) намеренно не включены (§4.2: AO только по
доказанной пользе; металла среди покрытий нет).

`checker/color.png`: 1024 px = 1 м, 8×8 клеток по 12.5 см (серые 90/200), тёмная линия каждые 128 px = 12.5 см.
Красная клетка — верхний левый угол изображения, синяя — верхний правый. При `flipY=true` (default `TextureLoader`)
красная клетка должна оказаться в UV (0,1), синяя в UV (1,1); если на поверхности красная внизу или справа — контракт
`flipY`/UV нарушен. Генератор — чистый node без зависимостей, 20 строк, при необходимости пересоздать по описанию.

## Отклонения от §11.T

- `oakFloor`/`oakFurniture` взяты с Poly Haven, а не ambientCG: у ambientCG дубовые полы либо оранжевые (WoodFloor051),
  либо паркет-мозаика (WoodFloor068–071), что противоречит §2 («без оранжевого лака»).
- Для `wallPaint` выбран Paint004, а не штукатурка (Plaster001/PaintedPlaster017): те дают крупное зерно, запрещённое §4.3.
- `stoneCounter`/`stoneSplash` — предложение по §2 (столешница темнее и глаже фартука), не определение материала по фото.
